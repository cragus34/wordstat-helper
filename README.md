# Wordstat Helper & Yandex SERP — Помощник SEO-специалиста

Веб-приложение для SEO-специалистов и редакторов, автоматизирующее сбор семантики из **Яндекс.Wordstat** и анализ органической поисковой выдачи **Яндекса (ТОП-10/20 сайтов)** без рекламы через API `jsonseo.ru`.

---

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/cragus34/wordstat-helper.git
cd wordstat-helper
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка API-ключа
Скопируйте шаблон конфигурации и укажите ваш API-ключ от сервиса [jsonseo.ru](https://jsonseo.ru):
```bash
cp .env.example .env
```
В файле `.env`:
```ini
JSONSEO_API_KEY=ваш_ключ_здесь
```

### 3. Запуск веб-сервера
```bash
uvicorn main:app --reload
```
Приложение откроется по адресу: **http://127.0.0.1:8000**

---

## 🌟 Основные возможности

### 1. Сбор семантики (Яндекс.Вордстат)
* Постраничный парсинг поисковых фраз по базовой маске.
* Фильтрация стоп-слов и минимальной базовой частотности.
* Сбор точной частотности `[!слово !слово]` с непрерывным сохранением в SQLite.
* Индикатор прогресса в реальном времени с возможностью безопасной остановки (кнопка «Стоп»).
* Автоматическая сортировка по точной частотности и экспорт в Excel (`.xlsx`).

### 2. Поисковая выдача Яндекса (SERP ТОП-10 / ТОП-20)
* **Чистая органика без рекламы**: сбор реальных позиций сайтов по запросу без блоков Яндекс Директа.
* **Гибкие настройки**:
  * Выбор региона (Москва, вся Россия, Санкт-Петербург, Казань и любой произвольный ID региона).
  * Выбор типа устройства (Desktop / Mobile).
  * Глубина выдачи (ТОП-10 или ТОП-20).
* **Удобные действия в один клик**:
  * 📋 *Скопировать URL* — копирует список прямых ссылок в буфер для анализа.
  * 📋 *Скопировать домены* — копирует список уникальных доменов конкурентов.
  * ⬇ *Скачать Excel* — стильный отчет со сниппетами, заголовками и кликабельными ссылками.

### 3. История запросов
* Все выполненные сборы семантики сохраняются в локальную базу данных SQLite (`history.db`).
* Возможность в любой момент открыть старый сбор и повторно скачать Excel.

## 1. Контекст и цель

SEO-редакторы тратят значительное время на ручной сбор семантики: нужно собрать фразы по маске из Яндекс Вордстата, затем отдельно проверить их частотность в сервисе json seo. Это рутинный двухэтапный процесс без автоматизации.

**Цель проекта:** создать веб-инструмент, который автоматически собирает список фраз по seed-маске из Яндекс Вордстата и обогащает их двумя видами частотности из json seo — базовой и точной ("!слово !слово"). Результат выводится в таблицу и экспортируется в Excel.

**Пользователи:** SEO-редакторы без технических навыков. Работают через браузер.

## 2. Роли и сценарии использования

### UC-01: Сбор семантики по маске
| | |
|---|---|
| **Кто** | SEO-редактор |
| **Действие** | Вводит маску «каркасная баня», мин. частотность 100, нажимает «Запустить» |
| **Система** | Собирает фразы из Яндекс Вордстата → фильтрует по порогу → запрашивает частотности в json seo |
| **Результат** | Таблица: фраза / базовая частотность / точная частотность |

### UC-02: Фильтрация по стоп-словам
| | |
|---|---|
| **Кто** | SEO-редактор |
| **Действие** | Задаёт стоп-слова «цена, недорого» вместе с маской |
| **Система** | Исключает из результата фразы, содержащие хотя бы одно стоп-слово |
| **Результат** | В таблице нет строк с указанными словами |

### UC-03: Экспорт в Excel
| | |
|---|---|
| **Кто** | SEO-редактор |
| **Действие** | Нажимает «Скачать Excel» после получения таблицы |
| **Система** | Формирует .xlsx файл с текущей таблицей |
| **Результат** | Файл скачивается в браузер |

### UC-04: Просмотр истории запросов
| | |
|---|---|
| **Кто** | SEO-редактор |
| **Действие** | Открывает раздел «История» |
| **Система** | Показывает список прошлых запросов: маска, дата, кол-во фраз |
| **Действие 2** | Нажимает на запись в истории |
| **Результат** | Открывается таблица результатов этого запроса |

### UC-05: Сбор органической выдачи Яндекса (SERP)
| | |
|---|---|
| **Кто** | SEO-редактор / оптимизатор |
| **Действие** | Вводит запрос «налоговый вычет для самозанятых», выбирает регион и глубину ТОП-10 |
| **Система** | Запрашивает `/api/yandex` с флагом `ads=0` (без рекламы) |
| **Результат** | Таблица ТОП-10 сайтов: позиция, домен, кликабельный Title/URL, сниппет |

## 3. Функциональные требования

| # | Требование |
|---|---|
| ФТ-01 | Система принимает на вход: seed-фразу, мин. частотность (число), список стоп-слов |
| ФТ-02 | Система возвращает таблицу с колонками: фраза, базовая частотность, точная частотность ("!слово !слово") |
| ФТ-03 | Фразы с базовой частотностью ниже минимального порога не включаются в результат |
| ФТ-04 | Фразы, содержащие хотя бы одно стоп-слово (без учёта регистра), исключаются |
| ФТ-05 | Парсинг ведётся постранично; останавливается, как только минимальная базовая частотность на странице опускается ниже порога |
| ФТ-06 | Точная частотность ("!слово !слово", kind="exact") запрашивается только для фраз, прошедших фильтрацию |
| ФТ-07 | Отображение прогресса: фоновая обработка задачи с индикатором процентов и текущего этапа |
| ФТ-08 | Возможность принудительной остановки сбора (кнопка «Остановить сбор») |
| ФТ-09 | Непрерывное сохранение в SQLite: запись в БД создаётся в момент старта, данные записываются по мере сбора каждой фразы |
| ФТ-10 | Сортировка результатов в интерфейсе и при выгрузке в Excel по умолчанию производится по убыванию точной частотности |
| ФТ-11 | Если API недоступен — система возвращает понятное сообщение об ошибке, не падает |
| ФТ-12 | Результаты таблицы экспортируются в файл .xlsx |
| ФТ-13 | Каждый запрос сохраняется в историю |
| ФТ-14 | История отображается списком; клик по записи открывает сохранённую таблицу |
| ФТ-15 | Поддержка вкладки «Поисковая выдача» с получением ТОП-10/20 сайтов без рекламы и возможностью копирования ссылок и выгрузки в Excel |
